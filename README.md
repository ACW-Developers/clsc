# CSLC System

A modern web application for managing hospitality services and online bookings at Christian Student Leadership Centre (CSLC), Ufungamano House.

## Highlights

- **Hospitality Services:** Organize accommodation, conference facilities, restaurant services, outdoor spaces, catering, and hostels.
- **Online Bookings:** Provide a foundation for customers to explore services and make reservations.
- **Admin Dashboard:** Monitor system activity, booking statistics, and operational records.
- **Service Management:** Create, edit, organize, and publish services and facilities, including images, descriptions, pricing, and capacity.
- **User Management:** Manage customer accounts and authorized administrative access.
- **Activity Logs:** Maintain visibility into administrative activities.
- **Authentication & Security:** Supabase-powered authentication, role-based access, and database security policies.
- **One-Time Admin Setup:** Secure initial super-administrator provisioning.
- **Responsive Design:** Accessible across desktop, tablet, and mobile devices.

## Technology Stack

- React, TypeScript, and Vite
- Tailwind CSS
- Supabase Authentication, PostgreSQL, and Storage

## Getting Started

1. Install dependencies using `npm install`.
2. Configure the required Supabase environment variables in `.env`.
3. Start the development server using `npm run dev`.
4. Run `npm run build` to verify the production build.

## Project Goal

Provide a secure, maintainable foundation for CSLC hospitality operations, with room to expand into comprehensive booking workflows, payments, reporting, and other institutional digital services.
